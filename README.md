I run **Hyde Open Source**, an organization focused on creating **free and open-source tools and software**.

Hyde isn't just one project.

It's an ecosystem.

The goal is simple:

> **Build useful software and keep it free and open source.**

### 🚀 Hyde Projects

#### 🎵 Hyde Music

A local-first, open-source music player focused on giving users a powerful and enjoyable music experience.

**Features & work include:**

* Local music playback
* Playlists
* YouTube integration
* Multiple audio formats
* Visualizer
* Desktop application
* Android development
* Backup & synchronization
* Open-source architecture
